- [ ] **Выбрать путь улучшения поиска кадров** (поиск в интернете 08.11, приложение бесплатное,
  некоммерческое, с открытым кодом):
  - *Своя крошечная модель (рекомендую; приложение должно работать и на слабых телефонах).*
    NanoDet-Plus-m (Apache-2.0): 1,2 млн параметров, файл ~1,2 МБ (INT8), ~12 мс на кадр
    320×320 на ARM-процессоре (данные авторов, 4 ядра A76; на слабом телефоне — в несколько раз
    дольше, проверю). Запускается через ncnn (BSD-3) — он уже есть в приложении для улучшения
    сканов, второй движок не нужен. D-FINE-N (Apache-2.0) точнее, но в ~8 раз тяжелее по
    вычислениям — запасной вариант. Обучить на Manga109-s (87 томов с разметкой рамок кадров;
    обученную модель можно использовать даже в коммерции; условия: указать Manga109-s, сам
    датасет не раздавать) плюс наши синтетические страницы (врезки, наклонные границы,
    страницы без полей). Страница считается один раз (результат уже кешируется), заранее, в
    фоне. Модель скачивается при включении, не в APK. Классический поиск остаётся: уточняет
    наклонные края и работает, пока модель не скачана или если её выключить.
    Нужно от вас: войти на Hugging Face и принять условия датасета `hal-utokyo/Manga109-s`
    (доступ выдаётся автоматически после согласия) — принимать условия за вас я не могу.
  - *Готовые модели:* Magi (лучшая для манги, сама расставляет порядок) — «только для научных
    исследований», бесплатное приложение под это не подходит; можно написать автору и
    попросить разрешение. Kumiko и YOLO (Ultralytics) — AGPL: открытый код это позволяет, но
    тогда всё приложение должно перейти на AGPL, а ваше правило — только MIT/BSD/Apache.
    DeepPanel (Apache-2.0) — старая модель для западных комиксов, датасет закрыт. MangaSeg
    (CVPR 2025, маски кадров с наклонами) — лицензия неясная, только с разрешения автора.
  - *Облачный ИИ по ключу пользователя* — для трудных страниц, нужен интернет, платит владелец
    ключа, страницы уходят в облако.
  - *В любом случае сначала* — эталонная разметка ~100 страниц и автоматическая оценка, чтобы
    мерить улучшения числом, а не на глаз.
